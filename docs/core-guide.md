# Guide Nodes

The Vonk guide nodes allow you to create Fusion viewer window guide overlay shapes. These custom guide (*.guide) files are saved to the "Guides:/" PathMap folder.

## Node Listing

Create:
- vGuideCreate
- vGuideShape
- vGuideText

IO:
- vGuideFromFile
- vGuideToFile
