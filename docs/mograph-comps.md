# Mograph Comps

## Comps Folder

You can access the example comps by navigating in Fusion Studio to the "Script > Vonk Ultra > Open > Show Comps Folder" menu item:

![Show Comps](Images/fusion-scripts-show-comps.png)

In Resolve Studio you can access the content using the "Workspaces > Script > Vonk Ultra > Open > Show Comps Folder" menu item:

![Show Comps](Images/resolve-scripts-show-comps.png)

The Vonk Ultra motion graphics examples are located on disk at the Pathmap location:

	Reactor:/Deploy/Comps/Kartaverse/Vonk Ultra/Demo Mograph

![Comps Folder](Images/comps-folder.png)

![Demo Mograph Folder](Images/comps-mograph-folder.png)
